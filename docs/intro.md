# Documentation

Pocket Nutrition makes meal logging fast and counts what cooking does to your food. It is open
source from end to end: the platform under AGPL-3.0, the apps under MPL-2.0. These pages explain
how it works, why it is built this way, and how to run it yourself.

New here? Start with **[How it works](./how-it-works.md)**: the whole system on one page.

## Why this project

Until recently, only large companies could afford to build a system like this one. The ideas
behind it are complex, and building them cost a lot of money. What they built stayed closed.

AI tools that write code have changed this. A small team can now build what once needed a large
company.

We wanted to seize this chance, and to do it in the open. Pocket Nutrition is open source from end
to end: anyone can read the code, check the numbers, run it on their own server or improve the
food data. It belongs to a community, not to a company.

Our goal: a solid, professional foundation that puts good nutrition within everyone's reach.
